# 对话断线续流

## 文档状态

实现中，待联调验证。

## 功能概述

为正式会话的 SSE 流式回答提供断线自动重连、事件回放和页面刷新自动恢复。目标用户是在网络短暂中断或刷新页面后继续获得同一次模型生成的回答，而不重复调用模型。

## 需求确认信息

- 确认日期：2026-08-01
- 确认依据：用户确认断线后不停止生成、单次服务端最长 5 分钟、刷新自动恢复、事件缓存 15 分钟、有限次数自动重连，并排除本次重新生成。
- 当前版本：1.0
- 需求来源：流式对话可靠性迭代
- 最后确认人：用户
