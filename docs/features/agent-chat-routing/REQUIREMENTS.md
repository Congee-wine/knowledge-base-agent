# 功能需求

## 1. 功能背景

现有 LangGraph 仅以“是否存在 ready 索引文件”决定知识库分支，无法区分个人 Agent 未绑定资料范围与已绑定但资料尚未完成索引，导致未绑定资料时可能错误返回“无可用资料”。

## 2. 功能目标

根据 Agent 类型、资料范围绑定、内置 AI 管家开关和索引状态，选择确定且可解释的问答路径。

## 3. 用户角色

已登录用户可使用内置 AI 管家或本人创建的个人 Agent；资料范围及全部资料库只允许访问当前用户资料。

## 4. 功能范围

### 4.1 本次包含

- 敏感身份、模型或内部配置问题走服务端固定回复。
- 个人 Agent 未绑定任何资料范围时，走普通模型回答，并推送明确状态说明未绑定知识库。
- 个人 Agent 已绑定范围但范围内没有 `processing_status=ready` 且 `index_status=ready` 的文件时，返回无可用资料提示，不调用模型生成通用答案。
- 内置 AI 管家在 `useKnowledgeBase=false` 时走普通模型回答；在 `useKnowledgeBase=true` 时使用当前用户的全部资料库。
- 有可用资料时：目录问题走资料目录查询；其他问题固定执行语义检索、证据评估和基于资料的生成。
- 检索异常、无可靠资料和有可靠资料必须走不同终态。

### 4.2 本次不包含

- 模型自主决定是否检索。
- 联网、外部工具调用或 ReAct 循环。
- 修改 SSE 帧格式、聊天持久化结构或数据库迁移。

## 5. 核心业务流程

```text
开始
  → 身份与安全守卫
  → 敏感问题：固定回复并结束
  → 普通问题：知识库能力检查
      → 个人 Agent 未绑定范围：状态说明 + 普通模型回答
      → AI 管家且全部资料库关闭：普通模型回答
      → 已启用资料范围但无 ready 文件：无可用资料提示并结束
      → 存在 ready 文件：请求分析
          → 资料目录问题：查询目录并结束
          → 其他问题：语义检索 → 证据评估
              → 检索异常：失败提示并结束
              → 无可靠证据：无匹配提示并结束
              → 有可靠证据：基于资料生成答案并结束
```

## 6. 详细功能需求

### FR-001：知识库路由能力判定

- 个人 Agent：仅在已绑定至少一个资料范围节点时启用知识库路径。
- 个人 Agent 未绑定范围：不得执行目录查询、向量检索或关键词检索；必须向前端推送“未绑定知识库，当前由模型直接回答”的状态，再调用普通模型回答。
- 内置 AI 管家：`useKnowledgeBase=true` 表示使用当前用户的全部资料库；`false` 表示普通模型回答。
- 已启用资料范围时，只有范围内存在 ready/current/已索引文档才可进入检索或目录分支。

### FR-002：知识库问答路由

- 有可用资料后，目录类问题调用真实目录查询并直接组织结果，不调用聊天模型猜测目录。
- 非目录类问题必须执行语义检索；不得退回普通模型回答。
- 检索服务异常返回检索失败提示；无达到既有阈值的最终上下文来源时返回无匹配提示；两者都不调用聊天模型。
- 仅存在可靠来源时，才将授权上下文交给模型生成回答并关联引用。

## 7. 边界情况

- 绑定空文件夹：视为已启用范围但无 ready 文件，返回无可用资料提示。
- 文档处理中或索引失败：不得作为可用资料；若无其他 ready 文件，同样返回无可用资料提示。
- AI 管家全部资料库关闭：不因当前用户存在资料而检索。
- 任何分支均不得越过当前用户资料隔离。

## 8. 非功能需求

- 路由必须由后端确定，前端参数不能绕过资料权限。
- SSE 仅推送可解释的状态摘要，不暴露模型配置或内部推理。
- 为新增的三类能力状态及所有终态补充自动化测试。
# 补充确认：FR-003 知识库概览

- 触发：用户询问知识库中有什么、有哪些文件/资料、资料目录，或基于资料可以回答什么问题。
- 前置条件：当前 Agent 的可访问范围内至少存在一份完成处理和索引的资料。
- 正常流程：读取授权范围内的资料及其代表性内容片段，流式返回资料概览；答案必须包含文件清单、每份资料的大致主题，以及基于这些资料可优先回答的问题类型。
- 约束：不得把代表性片段当作全文；无法从片段判断的内容必须明确说明；不得捏造文件、内容或能力范围。
- 异常：读取失败走“检索失败”终态；读取结果为空走“无匹配”终态；两种情况都不调用模型生成通用答案。
- 范围说明：概览使用每份文件的首个已索引片段，单片段最多 500 个字符，最多读取 30 份资料，以控制模型上下文长度。
