# 验收标准

## AC-001：个人 Agent 未绑定范围

- 前置条件：个人 Agent 在 `agent_knowledge_scopes` 中无任何绑定。
- 操作：发送普通问题。
- 预期：不调用目录或检索服务；SSE 先出现说明未绑定知识库的生成状态；模型正常流式回答；无引用来源。

## AC-002：个人 Agent 已绑定但无可用资料

- 前置条件：个人 Agent 已绑定范围，但范围内没有 ready/current/已索引文档。
- 操作：发送任意问题。
- 预期：SSE 出现 `no_documents`；返回固定无可用资料提示；不调用聊天模型。

## AC-003：内置 AI 管家全库开关

- `useKnowledgeBase=false`：不检索，走普通模型回答。
- `useKnowledgeBase=true` 且当前用户有 ready 文档：目录问题走目录查询，其他问题走语义检索。
- 任一情况下均不得访问其他用户资料。

## AC-004：有资料后的受控分支

- 目录问题：返回真实授权目录，不调用聊天模型。
- 普通问题且检索命中可靠来源：推送 `retrieving`、`context`、`sources`、`generating`，然后基于来源生成回答。
- 普通问题无可靠来源：推送 `no_match`，不调用聊天模型。
- 检索异常：推送 `retrieval_failed`，不调用聊天模型。

## AC-005：回归检查

- 身份、模型配置等敏感问题仍绕过模型与检索，固定回复。
- 现有 SSE 协议解析、断线续流、取消和消息持久化行为不变。
- 后端单元测试覆盖上述路由；前端 Hook 测试覆盖新增状态文案与步骤展示。
