# 验收标准

- 标题、段落和表格附近内容优先保持同一分块；超限内容按 token 切分且有可验证重叠。
- 同一 Worker 进程只加载一次 `bge-m3`，重启后复用持久化模型缓存。
- 每次检索先召回最多 8 条，最终上下文不超过 5 条有效来源。
- 候选召回至少包含向量与关键词两路；最终上下文必须经过本地重排，而不是直接采用向量 Top K。
- 每个文件最多有 2 个分块进入最终上下文，最终不超过 3 篇文件；引用文件数与最终来源可一一追踪。
- 对“数据库基本知识”“罗雅雯简历总结”等固定回归问题，游标分页文档不得在无直接证据时进入最终上下文或引用。
- SSE 的检索摘要不得将分块数表述为资料篇数。
- 知识库模式在存在 ready 索引文件时，每条用户问题均进入检索；“数据库基础知识”等未显式提及资料的泛化问法也不能跳过检索。
- 没有 ready 索引文件与检索无相关结果分别返回可区分的状态和说明，且两种情况均不得调用模型生成通用回答。
- 用户、非 ready 文件、未选资料范围和已删除文件均不能进入召回结果。
- 更新成功前旧版本可继续检索；更新失败不产生半成品索引。
- 每条聊天引用可返回已授权的原文件预览，且包含正确定位和不超过 160 字片段。
- 无命中、Worker 失败和模型失败不伪造引用，并有自动化与浏览器验收。
