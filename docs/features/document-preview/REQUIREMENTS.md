# 功能需求

## 功能目标

让资料树中的已处理文件可被其所有者安全地在浏览器内查看，且不改变上传、解析或后续检索链路。

## 本次包含

- TXT 与 Markdown 文本预览。
- PDF 浏览器内预览。
- DOCX 转换为仅含白名单结构的 HTML 后预览。
- 文件双击与右键“预览”进入同一预览页。
- 权限、处理中、空内容、格式不支持和预览失败提示。

## 本次不包含

- 文件编辑、下载、批注、PDF OCR、DOCX 图片或宏展示。
- 文本切分、向量化、检索与引用。

## 核心规则

1. 只有文件所有者可读取预览内容；不存在与越权访问均返回统一资源不存在结果。
2. 只有 `ready` 文件可预览；`uploaded`、`processing` 与 `failed` 文件不可预览。
3. TXT/Markdown 必须按 UTF-8 解码且去除空白后非空。
4. DOCX 输出必须由服务端生成，所有原始文本进行 HTML 转义；不保留脚本、事件属性、外部资源、宏或内嵌对象。
5. PDF 不使用对象存储预签名 URL；前端以 Bearer 认证请求获取 Blob 并创建临时 object URL。
