# 文件预览

## 文档状态

已实现。

## 功能概述

已登录用户可在资料树中预览自己已处理完成的 TXT、Markdown、PDF 和 DOCX 文件。预览始终经由后端鉴权，不向浏览器暴露私有对象存储地址。

- 需求来源：用户
- 最后确认人：用户

- `FRONTEND_DESIGN.md`：前端路由、状态与交互

- `API_DESIGN.md`：接口契约
- `ACCEPTANCE_CRITERIA.md`：验收条件
