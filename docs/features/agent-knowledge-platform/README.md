# 智能体与知识库首期能力

## 文档状态

已实现。核心链路（智能体管理、流式对话、知识库管理、RAG 检索、LangGraph 工作流）均已跑通，进入验收与打磨阶段。

## 功能概述

本功能为已登录用户提供内置 AI 管家、个人智能体、会话历史和私有知识库。用户可创建智能体、将某一智能体设为 AI 管家入口的默认打开对象，并为该智能体选择个人知识库中的文件或文件夹。运行时通过 LangGraph 工作流先分析问题与上下文，再决定直接回答、检索资料或目录查询；检索采用向量 + 关键字混合检索 + RRF 融合 + Rerank 重排的多阶段 Pipeline。
