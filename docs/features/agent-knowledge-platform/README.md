## 功能概述

本功能为已登录用户提供内置 AI 管家、个人智能体、会话历史和私有知识库。用户可创建智能体、将某一智能体设为 AI 管家入口的默认打开对象，并为该智能体选择个人知识库中的文件或文件夹。系统根据已选资料进行检索增强回答，并保存可追溯的会话与引用。
