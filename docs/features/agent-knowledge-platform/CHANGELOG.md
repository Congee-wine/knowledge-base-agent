- **影响的接口**：API-008 的前端消费实现，不改变服务端 SSE 契约。
- **影响的数据结构**：`document_chunks.embedding_model` 固定记录 `bge-m3`。

## 2026-07-20：首期资料类型调整为文字资料

- **变更类型**：需求修改 / 设计调整
- **变更状态**：已确认
- **变更原因**：用户希望降低首期 OCR 和部署复杂度。

- **影响的需求编号**：FR-004、FR-005。
- **影响的前端模块**：资料上传格式提示和失败状态。
- **影响的后端模块**：移除 OCR 适配与运行依赖；新增 DOCX 正文提取。
- **影响的接口**：API-010 的文件类型校验。
- **影响的数据结构**：无表结构变化。
- **是否需要修改测试**：是；更新文件类型、扫描 PDF 失败和文档处理测试。
- **是否需要迁移已有数据**：否；当前功能尚未实现。
