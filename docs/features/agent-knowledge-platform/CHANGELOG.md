# 需求与设计变更记录

## 2026-07-24：创建前基础信息与私有头像

- 新建智能体入口调整为先填写头像、名称、交互类型和描述；确认后创建智能体并进入既有完整配置页。
- 首期仅允许 `text` 交互类型；语音和数字人选项在前端显示为暂未开放。
- 头像仅接受 PNG/JPG/JPEG/GIF/WEBP，最大 5MB；服务端按文件签名校验后写入 MinIO 私有 Bucket，数据库只保存对象键。
- 新增经认证的头像读取接口，浏览器通过授权请求获取 Blob，不暴露公开对象 URL。

- **变更状态**：已实现，待浏览器人工比对

## 2026-07-24：确认智能体管理列表与删除可见性规则

- **变更类型**：需求确认与阶段 2 实现
- **变更状态**：已确认、已实现，待浏览器人工联调
- **变更内容**：智能体列表与左侧“我的智能体”使用真实 API 数据；默认项显示橙色标签并置顶。内置 AI 管家保留三点菜单，仅可恢复为默认打开。自建智能体菜单仅包含设为默认、编辑和删除。
- **删除规则**：删除采用既有软删除；用户不能再从卡片、侧栏、聊天页或会话入口访问该智能体及其历史，不提供恢复或历史浏览入口。
- **配置变化**：`allowNetworkAccess` 已通过迁移和 API 持久化，仅控制个人智能体聊天输入区联网按钮显示；实际联网功能仍未实现。

## 2026-07-23：确认聊天输入入口与资料检索开关规则

- **变更类型**：需求与交互设计确认
- **变更状态**：已确认
- **变更原因**：根据 AI 管家原型明确资料检索、联网、上传、语音和 Agent 模式入口的显示规则及后续实现边界。
- **变更前**：AI 管家资料检索默认行为、个人智能体的空资料处理，以及联网入口的配置来源未明确；原型中的新建文档卡片是否保留未明确。
- **变更后**：AI 管家的“全部资料”首次默认选中，关闭后直接模型回答；个人智能体绑定资料但无可用内容时提示“知识库暂无内容”后直接模型回答，未绑定时直接模型回答；AI 管家始终显示联网入口，个人智能体联网入口由创建/编辑配置决定；AI 管家首页不展示新建文档卡片。上传、麦克风和 Agent 模式入口按确认的显示规则呈现，实际能力后续实现。
- **用户是否确认**：是。
- **影响的需求编号**：FR-002、FR-005。
- **影响的前端模块**：聊天输入区、智能体创建/编辑表单、知识库入口。
- **影响的后端模块**：智能体配置持久化、未来检索与模型请求编排。
- **影响的接口**：个人智能体请求增加 `allowNetworkAccess`；未来模型消息请求增加 `useKnowledgeBase`。
- **影响的数据结构**：后续迁移为 `agents` 增加 `allow_network_access`，不修改现有会话/消息表。
- **是否需要修改测试**：是；后续增加按钮显示规则、联网配置持久化和资料开关检索分支测试。
- **是否需要迁移已有数据**：是；在实现个人智能体创建/编辑页面前新增字段迁移。

- **是否需要修改测试**：是；覆盖写入顺序、标题/更新时间和越权拒绝。
- **是否需要迁移已有数据**：否。

- **是否需要修改测试**：是；新增内置标识、默认清空、默认删除保护和用户隔离测试。
