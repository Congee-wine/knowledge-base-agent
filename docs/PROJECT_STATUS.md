## 已完成功能

### 认证系统（已完成）
- 注册、登录、JWT 双 Token 认证（Access + Refresh）
- Refresh Token 滑动续期与会话级 Token 吊销
- 前端无感刷新与并发安全控制
- 路由守卫（登录回跳、匿名/受保护路由边界）
- 后端集成测试（5 个用例覆盖重复注册、错误密码、令牌轮换、重放拒绝、登出撤销）

### 智能体管理（已完成）
- 智能体 CRUD（创建、编辑、删除）
- 设为默认智能体、内置 AI 管家（不可修改删除）
- 智能体头像上传（MinIO 对象存储）
- 系统提示词 Markdown 编辑器（`@uiw/react-md-editor`）
- 智能体知识范围绑定（资料树选择器、目录浏览、搜索、多选）
- 编辑页实时对话预览（不持久化）
- AI 管家预设问题更新为资料上传、整理、检索与资料管理等已实现能力对应的引导（待执行数据库迁移）

### 会话与流式对话（已完成）
- SSE 流式对话（正式会话 + 编辑预览双模式）
- 前端自研 SSE 解析器（分块传输、CRLF、多行 data、末尾无空行）
- 多会话并行流式、生成中断与状态同步
- 乐观更新 + 本地/服务端消息合并（`mergeMessages`）
- Markdown 流式渲染（`@ant-design/x-markdown` streaming 模式）
- 引用来源展示（可折叠编号资料列表、按资料去重）
- 运行步骤可视化（`ChatRunSummary` 可折叠大步骤 + 结构化子步骤）
- 消息复制、回到底部按钮、自动滚动跟随
- 会话列表、历史消息加载、会话创建幂等性
- 后端仓储层事务、回复关系、消息排序、并发幂等性测试

### 知识库管理（已完成）
- 树形目录结构（创建文件夹、上传文件、重命名、移动、递归删除）
- 5 层嵌套限制、同名校验、账号隔离
- 支持 PDF、TXT、Markdown、DOCX 四种格式
- MinIO 对象存储集成（上传、读取、删除）
- 异步文档处理流水线（RQ 队列：上传 → 解析 → 分块 → Embedding → 索引）
- 文档版本管理（`document_versions` 表 + `is_current` 标记）
- 处理状态追踪（`uploaded` → `processing` → `ready` / `failed`）
- 失败重试与清理（失败时清理资料记录和对象存储文件）
- 受认证文件预览（PDF Blob URL、DOCX 沙箱 iframe、TXT/Markdown 文本）
- 前端多选批量操作栏、右键上下文菜单、面包屑导航

### RAG 检索增强生成（已完成）
- 混合检索策略：向量检索 + 关键字检索 + RRF 融合排序
- BGE-M3 多语言 Embedding（中英文，通过 RQ 远程调用 Worker）
- BGE-Reranker 交叉编码器重排（通过 RQ 远程调用 Worker）
- pgvector 余弦相似度检索
- 智能文档分块（标题检测 + 语义边界 + 180 字符重叠窗口）
- 文件级上下文限额（每文件最多 2 个片段）与重排分数阈值（0.30）
- 检索可观测性（候选集、排序分数、选中原因持久化到 `retrieval_runs` 表）
- 关键字提取（拉丁词 + 中文二元组/三元组，停用词过滤）

### LangGraph 智能体工作流（已完成）

## 已知风险与技术债务

- 前端将访问令牌和刷新令牌存入 `localStorage`；XSS 发生时令牌可能暴露。生产场景应重新评估 HttpOnly Cookie 等方案。
- 生产构建的 JavaScript 主包约 2.13 MB（含 Markdown 编辑器等依赖）；路由已具备按需加载基础，但模块内代码分割尚未实施。
- `query_embeddings.py` 使用轮询等待 RQ 结果（`time.sleep(0.1)` 循环），非最优方案；后续可改为 RQ 回调或 Redis Pub/Sub。
- 会话列表未实现 cursor 翻页，当前以最多 100 条参数限制返回。
- 本地 Compose 中的 MinIO 初始账号仅限开发环境；部署前必须改为受控凭据。
