# 问题记录

## Q-20260718-002：前端路由是否需要按认证与业务边界重构

- **日期**：2026-07-18
- **状态**：已解决
- **涉及模块**：前端路由、认证、应用布局
- **用户问题**：前端的路由配置是不是不合理，并要求基于诊断方案修改。
- **问题背景**：原实现通过用户状态切换两套 `Routes`，匿名状态下以 `*` 匹配全部地址，认证页模式不由 URL 表达，业务路径命名也不统一。
- **最终结论**：采用显式 `/login`、`/register`、`/app/*` 和独立 404 页；通过守卫组件隔离匿名与受保护路由，登录后恢复原目标地址，并将路径常量集中管理。
- **实现影响**：新增 `frontend/src/routes/`；导航与路由声明复用路径常量；原 `/robot/chat`、`/document` 不再是有效入口。
- **后续事项**：各业务页完成时，在 `/app/chat`、`/app/agents`、`/app/knowledge-bases` 下补充子路由，并评估路由级懒加载。

## Q-20260718-001：项目文档应以哪些状态为准

- **日期**：2026-07-18
- **状态**：已确认
- **涉及模块**：项目文档、前端、后端、CI
- **用户问题**：如何根据当前项目代码和目录结构补全项目状态、开发日志、问题记录、技术决策和架构文档。
- **问题背景**：仓库根目录缺少统一 `docs/`，而已有实现中同时存在已编码功能、空页面和未进行集成验证的部分。
- **最终结论**：以仓库当前代码、配置和实际命令结果为唯一事实来源；已编码但未联调的内容标为“待验证”，无实现的知识库与智能体能力标为“规划中”或“未实现”。
- **实现影响**：`docs/` 下的状态、架构、决策与日志均采用上述标注；后续功能完成后应在同一文档体系中更新状态。
- **后续事项**：执行数据库和 API 集成测试后，更新认证相关验证状态。
